
# 🚗 Car Sales Analysis

### End-to-End Data Analytics Project Using Python, SQL & Power BI

## 📌 Project Overview
This project focuses on analyzing car sales data to identify sales trends, customer preferences, brand performance, and regional sales insights.

The project uses Python for data cleaning and exploratory data analysis, MySQL for data querying, and Power BI for interactive dashboard development.

## 🎯 Project Objectives
- Analyze overall car sales performance.
- Identify top-performing car brands and models.
- Analyze revenue and average selling prices.
- Understand fuel type and transmission preferences.
- Compare regional sales performance.
- Build an interactive Power BI dashboard.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Power BI
- Jupyter Notebook

## 📂 Project Workflow

### 1. Data Cleaning & Preprocessing (Python)
- Removed duplicate records.
- Handled missing values.
- Converted date columns into datetime format.
- Performed data validation.
- Exported the cleaned dataset.

### 2. Exploratory Data Analysis (Python)
- Brand-wise sales analysis.
- Fuel type distribution.
- Transmission analysis.
- Regional sales analysis.
- Selling price distribution.
- Mileage analysis.
- Correlation analysis.

### 3. SQL Analysis (MySQL)
- Total number of cars sold.
- Total revenue and average selling price.
- Fuel type distribution.
- Transmission-wise sales.
- Top-selling brands and models.
- Region-wise sales analysis.
- Brand-wise revenue.
- Average mileage by brand.
- Premium car analysis.

### 4. Power BI Dashboard
Developed an interactive dashboard with:
- Total Cars Sold
- Total Revenue
- Average Selling Price
- Top Selling Brand
- Sales by Region
- Top 5 Brands by Sales
- Sales Distribution by Fuel Type
- Sales Distribution by Transmission
- Average Selling Price by Fuel Type
- Top 5 Car Models by Sales

Interactive slicers:
- Year
- Brand
- Fuel Type
- Transmission
- Region
